About Web Doc

Web Doc is a professional-grade website vulnerability scanner developed as an academic project by students of APS College of Engineering. Our mission is to make enterprise-level security scanning accessible while providing comprehensive coverage of modern web vulnerabilities.

This tool incorporates the latest OWASP Top 10 standards for both 2021 and 2025, offering real-time risk assessment, detailed vulnerability analysis, and professional reporting capabilities.
